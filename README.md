# 最強蝸牛・小夥伴能力模擬器

一頁看完所有小夥伴的六種族數值、等級與能力，數值依等級自動換算。

**線上使用：<https://cyc6221.github.io/snail-partner/>**

> 目前開發中，數值以遊戲內為準。

## 目前內容

- **小夥伴能力**：每位小夥伴的六種族數值、等級、六圍與能力，等級由六圍自動換算。
- **小夥伴檔案**：所有小夥伴的編號、等級、六圍與本命種族一覽。
- **兵種檔案**：每種兵種由誰帶領，以及上陣加成。
- **能力加總**：把所有小夥伴的同名能力加總，分成蝸牛屬性、兵種、部隊加成、研究基因、醫療等分頁。
- 目前收錄 31 位。

## 資料來源

數值為玩家自行整理，資料持續更新中，發現錯誤或有新資料，歡迎開 Issue。

## 開發

純前端，沒有任何相依套件，小夥伴資料在 `data/partners.js`。
