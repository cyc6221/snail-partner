# 最強蝸牛・小夥伴能力模擬器

一頁看完所有小夥伴的六種族數值、等級與能力，數值依等級自動換算。

**線上使用：<https://cyc6221.github.io/snail-partner/>**

> 非官方玩家自製工具，目前開發中，數值以遊戲內為準。

## 目前內容

- 左右兩欄排列小夥伴檔案，有些檔案會橫跨兩欄。
- 每張檔案顯示等級與「六圍」（六種族數值加總，含特別加成），種族為喪屍、惡魔、天使、異種、機械、巨龍。
- 本命種族那一格會突出顯示；有特別加成時顯示成「90+10」。
- 能力分成兩欄（料理／技能、指揮），數值為「等級 × 每級增加量」。兵種名稱會突出顯示。
- 支援深色／淺色模式（依系統設定），手機會自動改成單欄。

目前收錄：頂罐子蝸牛、朴巨姬、猗猗卡卡、王子的靈魂、豐田次郎。

## 資料來源

- 數值為玩家自行整理，資料持續更新中。

發現錯誤或有新資料，歡迎開 Issue。

## 開發

純前端，沒有任何相依套件。

- 小夥伴資料都在 `data/partners.js`，每位的欄位（`values`、`level`、`main`、`bonus`、`abilities`）說明寫在檔案開頭的註解。
- 程式在 `js/`，樣式在 `css/`。
- 部署：GitHub Pages（Settings → Pages → `main` / root）。
