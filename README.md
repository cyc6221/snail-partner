# 最強蝸牛・小夥伴能力模擬器

一頁看完所有小夥伴的六種族數值、等級與能力，數值依等級自動換算。

**線上使用：<https://cyc6221.github.io/snail-partner/>**

> 目前開發中，數值以遊戲內為準。

## 目前內容

- 依等級換算每位小夥伴的六種族數值與能力。
- 目前收錄 22／31 位：頂罐子蝸牛、朴巨姬、猗猗卡卡、王子的靈魂、豐田次郎、蔥音、未來貓、連名字都不能提的人、滄龍、龍女中樞、蛞蝓龍家教、惠子、赤兔馬・雌、李建綱、于吉、尼安德塔人、諸葛亮、下水道烏龜、魔春姬、機械蝸牛、開發組成員、厄夢偵探。

## 資料來源

數值為玩家自行整理，資料持續更新中，發現錯誤或有新資料，歡迎開 Issue。

## 開發

純前端，沒有任何相依套件，小夥伴資料在 `data/partners.js`。
